== Overview

This manual introduces the {project} project providing concepts, architecture, conventions, procedures and best practices for its users.

The {project} is a collaborative effort devoted to building a common low-level software enviroment or "fabric" the for RISC-V hardware ecosystem. Low-level in this case means that no software stack (e.g. bootloader, operating system, run-time libraries) is assumed to be present in the target machine.

=== What's in the {project}

* A well-defined, model-based and modular software architecture
* A CMake-based build environment, including toolchain files
* A common set of run-time libraries
* A hardware (e.g. devices, machines, etc) meta-model definition
* Basic device and machine models
* Model to code generation tools
* A build management tool to wrangle all of the above (`rave`)

=== What's NOT in the {project}

* An operating system
* An integrated development environment
* Hardware design/verification tools
