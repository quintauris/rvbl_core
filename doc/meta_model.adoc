== Overview

Quintauris' machine meta-model defines the structure and properties of machine models employed across the {project}.

The top-level machine meta-model is a composition of smaller, more purpose-specific meta-models. The following is a simplified, top-level description of the meta-model hierarchy:

== Evaluated expressions

Attributes marked `Yes` in the `Expression` column are strings that shall be evaluated by model consumers to produce an integer result (e.g. `4096 * 8` o `4K * 16`).

Supported operators are:

* `()`: parentheses for grouping and precedence
* `+`, `-`, `*`, `/`: arithmetic operators
* `%`: modular division

Supported built-in functions are (both can take any number of parameters):

* `min()`
* `max()`

The following number formats are supported:

* Signed integer in base 10
* Unsigned intenger in base 16, prefixed by `0x`
* Signed decimal, using `.` as decimal separator

== Import

Imports allow bringing model elements defined in a separate file into the context where the import is made, under a user-defined name. For example, the follwing code brings the model entity defined in `riscv/model/ns16550/model.json` to the current context, under the name `ns16550`:


----
  "imports": {
    "ns16550": {
      "file": "riscv/model/ns16550/model.json"
    }
  }
----

Now `ns16550` which can be used by <<_reference>>s to produce `ns16550` instances under `peripherals`:

----
  "uart0": {
    "reference": "ns16550",
    "peripheral": {
      "base": "0x10000000"
    }
  },
----

[cols="2,1,1,1,4"]
|===
|Name |Type |Expression |Default value |Description

|`file`
|string
|No
|__Mandatory__
|File containing the entity to import, relative to a search path determined by the tool consuming the model.

|`substitutions`
|object
|N/A
|__Mandatory__
|Key/value substitutions to apply to string values in the imported entity
|===

`substitutions` can be used to apply custom changes to the imported entity, for example:

----
  "imports": {
    "ns16550": {
      "file": "riscv/model/ns16550/model.json"
      "substitutions": {"FOO": "BAR"}
    }
  }
----

will replace every occurence `$FOO` in `riscv/model/ns16550/model.json` string values with `BAR`.

=== Constraints

ctr_impr_001:: Keys within `substitutions` must conform to the following regular expression: `[A-Z]+[0-9a-zA-Z_]*`

== Reference

References instantiate <<_import>>ed elements, possibly setting/overriding some of its uniquely identifying attributes such as peripheral base address or peripheral instance id:

----
  "uart0": {
    "reference": "ns16550",
    "peripheral": {
      "base": "0x10000000"
    }
  },
----

In the above example, peripheral is instantiated as `uart0` with base address `0x10000000`.

== Register

Registers are word-aligned data instances within <<_addressable>>s. How individual registers are accessed is determined by the register's `class` attribute:

`memory_mapped`:: register is accessed via common fetch/store instructions on the register's address (parent's `offset` + `offset` determines the absolute address)
`control_status`:: register is accessed via direct RISC-V's CSR read/write instructions (parent's `offset` + `offset` determines the CSR index)

ctr_perp_008:: All names under `overlappings` shall reference valid <<_addressable>> names under `addressables`
ctr_perp_009:: <<_indexing>> keys shall conform to the following regular expression: `[a-zA-Z]+[0-9a-zA-Z_]*`

== Parameter

Parameters attach custom data to code and other artifacts generated after <<_machine>> and <<_peripheral>> model elements.

[cols="2,1,1,1,4"]
|===
|Name |Type |Expression |Default value |Description

|`stage`
|string
|No
|__Mandatory__
|One of `compile`, `link`, `run`. Determines the stage at which the parameter value is to be defined

|`class`
|string
|No
|__Mandatory__
|One of `uint8`, `uint16`, `uint32`, `uint64`, `uint128`, `int8`, `int16`, `int32`, `int64`, `int128`. Determines the type of the parameter

|string
|Yes
|__Mandatory__
|String representation of the parameter's numerical default value
|===

=== Constraints

ctr_parm_001:: `value` must evaluate to an unsigned integer number if `class` is unsigned (i.e. `uint8`, `uint16`, `uint32`, `uint64` or `uint128`)
ctr_parm_002:: `value` must evaluate to a signed integer number if `class` is signed (i.e. `int8`, `int16`, `int32`, `int64` or `int128`)
