= Meta-Model
Quintauris <www.quintauris.com> (generated {localdatetime})

== Overview

Quintauris' machine meta-model defines the structure and properties of machine models employed across the {project}.

The top-level machine meta-model is a composition of smaller, more purpose-specific meta-models. The following is a simplified, top-level description of the meta-model hierarchy:

image::meta_model.svg[]

== Common Attributes

All model entities share the following attributes:

[cols="2,1,1,1,4"]
|===
|Name |Type |Expression |Default value |Description

|`description`
|object
|N/A
|N/A
|Human-friendly description of the entity, for documentation purposes

|`description/content_type`
|string
|No
|`text/plain`
|MIME type of `content`

|`description/content`
|string
|No
|__Mandatory__
|Description content in the format specified by `content_type`

|`vendor`
|object
|N/A
|`{}`
|Vendor-specific data associated with the entity

|`vendor/__vendor_name__`
|object
|N/A
|`{}`
|Vendor-specific data over a vendor-defined structure
|===

For conciseness and readability, these attributes are omitted in the following sections.

=== Constraints

ctr_comm_001:: __vendor_name__ must conform to the following regular expression: `[a-zA-Z]+[0-9a-zA-Z_]*`
ctr_comm_002:: `description/content_type` must be one of `text/plain`, `text/markdown` or `text/html`
ctr_comm_003:: No two array elements under `vendor` shall have the same `name` value

== Computed values

=== Constraints

ctr_fild_001:: `position` must be an integer number in the range `[-(w-1), w-1]` where `w` is the value of the `width` attribute from the enclosing <<_register>>
ctr_fild_002:: `length` must be an integer number in the range `[1, w]` where `w` is the value of the `width` attribute from the enclosing <<_register>>
ctr_fild_003:: <<_value>> keys shall conform to the following regular expression: `[a-zA-Z]+[0-9a-zA-Z_]*`
ctr_fild_004:: In `on_read` values `clear`, `set`, `toggle` and `modify` are mutually exclusive
ctr_fild_005:: `on_write` keys shall be base-2 (i.e. binary) values
ctr_fild_006:: In `on_write` values `clear`, `set`, `toggle` and `modify` are mutually exclusive
ctr_fild_007:: Each element of `ranges` must be a 2-element array of strings that evaluate to integer numbers
ctr_fild_008:: If both `values` and `ranges` are defined, values in `values` must all be contained by `ranges`
ctr_fild_009:: `on_reset/__array-index__/name` shall reference a valid <<_reset>> defined at <<_machine>> level
ctr_fild_010:: `on_reset/__array-index__/value` shall be valid base-2 (i.e. binary) values, with no more bits than `length` bits
ctr_fild_011:: `on_reset/__array-index__/mask` shall be valid base-2 (i.e. binary) values, with no more bits than `length` bits
ctr_fild_012:: <<_indexing>> keys shall conform to the following regular expression: `[a-zA-Z]+[0-9a-zA-Z_]*`
